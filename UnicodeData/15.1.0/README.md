# Unicode 15.1.0 source inputs

These files are unmodified data from the Unicode Character Database 15.1.0.
They are inputs to `Scripts/generate-unicode-15.1.mjs`, and the conformance
tests read the official Normalization and Word Break fixtures directly.

The source URLs, SHA-256 values, license, and reproducible update procedure are
documented in `docs/unicode-15.1-evidence.md`.

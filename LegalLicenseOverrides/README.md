# License overrides

The pinned `swift-xet` revision predates the license file now published by its
upstream repository. `swift-xet-LICENSE.txt` is the upstream project's current
Apache License 2.0 text and is used only when regenerating the checked-in notice
inventory for that pinned revision.

Remove this override after updating to a revision that contains its own license
file. Do not add overrides here without confirming the terms with the upstream
publisher.

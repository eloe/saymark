Native macOS · Local-first · Apple silicon

The codebase, explained.

A native, local-first macOS menu-bar dictation app that captures speech, transcribes it on Apple silicon, and inserts final text into the focused application.

Swift SwiftUI + AppKit MLX macOS 15+ arm64 JSON source
System shape

Three layers. One direction.

Presentation may depend on SaymarkKit; SaymarkKit may depend on model and platform libraries. Model libraries must not depend on the app.

Critical path

Hotkey to final text.

The UI responds first. Audio and inference stay serialized. Final decoding leaves the main actor, then one single-shot paste attempts delivery with bounded acknowledgement.

01 Reject the gesture if disabled, already active, or models are not ready
02 Present the HUD synchronously on the main actor
03 In Start/Stop mode, show the click-through blue halo on the active display
04 Start a fresh DictationSession and MicCapture
05 Capture the focused AX element and selection lease when in-field delivery is requested
06 Capture and convert audio to 16 kHz mono
07 Stop at 10 minutes or fail closed when queued and active audio exceeds 5 seconds
08 Emit 160 ms chunks on the capture queue
09 Serialize VAD and ASR on saymark.stt
10 Publish live updates to the HUD
11 On hold release or the second Start/Stop press, hide the halo, display Processing, and stop capture
12 Finalize off the main actor
13 Use Parakeet final text in Efficient and Live Preview
14 Apply the frozen deterministic Vocabulary snapshot to final text
15 After a successful Start/Stop result, briefly fade the active-display edge green
16 Paste once only while the original AX lease remains current and require bounded delivery acknowledgement
17 Retain recovery through the clipboard only while Saymark still owns it; after ownership loss preserve a newer user clipboard, report failure in the HUD, and recover final text only from eligible committed history
18 Write eligible final text to Recent Dictations only when its opt-in retention policy remained enabled
19 Tear down per-utterance resources and schedule HUD dismissal
Final authority: Parakeet for product modes; Nemotron is live draft and empty-final fallback only
Product policy

Experiences, not model soup.

Users choose a supported experience. The core owns which models load, which text is provisional, and which output wins.

ExperienceModeModelsFeedbackFinal authorityNotes
EfficientFirst-run default accurate parakeet On release parakeet Product mode
Live Preview hybrid nemotronparakeet Live parakeet nemotron only when Parakeet final is empty
Fast fast nemotron Live nemotron Benchmarks and diagnostics only
18 GiB

MLX safety ceiling. Model residency is process-lifetime and expected. Per-utterance capture, audio buffers, sessions, subscriptions, timers, and HUD content are not—they must be torn down after every dictation.

Regression firewall

Rules the code must keep.

These are architecture decisions born from latency, accuracy, memory, trust, and privacy failures. Changing one requires evidence.

✓

Parakeet owns final text in Efficient and Live Preview; Nemotron may not overwrite a non-empty Parakeet result.

Live drafts are provisional and may be less accurate.

final-authority
✓

Present the HUD before starting AVAudioEngine or model work.

Hotkey feedback must feel immediate.

instant-feedback
✓

Run session.stop and final decoding off the MainActor.

Finalization must not freeze UI transitions.

no-main-thread-finish
✓

Serialize MLX and VAD session work on saymark.stt.

Shared inference state is not concurrency-safe.

single-inference-domain
✓

Keep the production feed at 2560 samples or repeat the versioned cadence experiment before changing it.

Feed cadence changes update frequency, MLX throughput, step latency, energy, and backlog behavior.

bounded-feed
✓

Stop live microphone capture at 10 minutes and reject more than 5 seconds of queued or active audio; these bounds do not govern future offline-file transcription.

A stalled or overloaded live session must not retain unbounded audio or insert partial output.

bounded-live-capture
✓

Distinguish expected process-lifetime model residency from per-utterance resources, which must be released.

This prevents both false memory alarms and real staircase leaks.

resource-separation
✓

Never log or transmit audio, transcript text, clipboard contents, selected text, or focused-field contents.

Dictation content is sensitive user data.

privacy
✓

Production ASR and VAD models must load only from immutable revisions whose critical artifacts match checked-in exact byte sizes and SHA-256 values.

Model weights are executable content and must not change independently of a reviewed Saymark source change.

pinned-models
✓

Install development builds with the stable Saymark Local identity.

Accessibility trust is tied to application identity.

stable-local-trust
✓

Do not bootstrap the live menu app until onboarding finishes.

Onboarding must own permission, download, and try-it sequencing without duplicate sessions.

onboarding-isolation
✓

Show the display-edge halo only while Start/Stop mode is actively listening; hide it during processing and honor Reduce Motion.

The halo is a recording-state affordance, not ambient decoration or a repeating animation.

toggle-halo
✓

Current builds lease the intended AX field and selection, post one final paste only while that intent is current, and require bounded acknowledgement before clipboard restoration. Clipboard ownership loss preserves the newer user copy. Planned live insertion may revise only Saymark-owned provisional text and must retain single-shot final paste as the compatibility fallback.

Focus, selection, protection, timeout, target, or clipboard ambiguity must produce no late paste or overwrite of user-owned content; recovery may use the still-owned clipboard or eligible committed history, while the HUD reports failure without retaining the final text.

safe-insertion

Privacy and platform

Every external edge is named.

Model downloads are networked. Dictation is local. Automatic insertion is gated by macOS trust. Remote analytics is dormant.

ON

Hugging Face Hub

Outbound HTTPS · Model setup or cache miss

Repository and artifact requests; never audio or transcripts
OFF

PostHog EU

Outbound HTTPS · Only a future configured build after explicit consent

Source and local builds embed an empty project token
GATED

macOS microphone

System input · Active dictation

Requires user permission
GATED

Focused application

Synthetic Command-V · Final insertion

Requires Accessibility and no secure input
